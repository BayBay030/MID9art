首圖（首頁那張滿版大圖）尺寸建議
========================================


【比例】16:9  （寬 : 高 = 1.78 : 1）

【尺寸】2400 × 1350 px
        最低 1920 × 1080。再大沒意義，螢幕吃不下，只會拖慢速度。

【檔案】JPG，壓到 500KB 以內。
        超過 1MB，手機開起來會先一片空白好幾秒。

【方向】橫式。
        不要用超寬全景（像 6480×2700 那種 2.4:1 的），也不要用直式。


----------------------------------------
最重要的一條：主角放正中間
----------------------------------------

首圖是「滿版全螢幕」，網頁會自動裁切去填滿畫面。
螢幕形狀不一樣，裁掉的地方就不一樣。

用 16:9 的圖來說，實際看得到的範圍大約是：

    電腦 / 筆電      中間約 9 成      （幾乎完整）
    平板 直立        中間約 4 成
    手機 直立        中間約 1/4       ← 最兇

也就是說，圖片左右兩側的東西，手機一律看不到。

所以：
  - 簽名、logo、想讓人看到的主體，全部往中間放
  - 左下角會被「藝術家姓名」那行白字壓到，那一塊留空
  - 兩側只放背景、留白、不重要的東西


----------------------------------------
如果手機一定要看到完整畫面
----------------------------------------

那就要另外準備一張直式的（比例 3:4 或 9:16），
讓手機吃直式、電腦吃橫式，兩張分開用。
這要改一點程式，需要的話跟我說。




========================================
網站分頁結構
========================================

訪客從選單看到的，是這樣一棵樹：


  Mr.Mid9 ........................ index.html
  │                                （首頁，滿版大圖輪播）
  │
  ├─ 作品（滑鼠移過去展開下拉）
  │   ├─ 2026 ................... work-2026.html
  │   ├─ 2025 ................... work-2025.html
  │   └─ 2024 ................... work-2024.html
  │
  ├─ 關於 ....................... about.html
  ├─ 動態 ....................... news.html
  ├─ 聯絡 ....................... contact.html
  ├─ 表單 ....................... form.html
  │                                （嵌 Google 表單）
  │
  └─ ZH / EN
      這個不是頁面，是同一頁換語言。


選單上看不到、但確實存在的兩頁：

  404.html ........... 網址打錯時自動跳出來的頁
  coming-soon.html ... 施工中頁。綁網域測試用，
                       上傳到主機時要改名成 index.html


----------------------------------------

----------------------------------------

James web/
│
├─ index.html ............ 首頁
├─ about.html ............ 關於
├─ news.html ............. 動態
├─ contact.html .......... 聯絡
├─ form.html ............. 表單
├─ work-2026.html ........ 作品 2026
├─ work-2025.html ........ 作品 2025
├─ work-2024.html ........ 作品 2024
├─ 404.html .............. 找不到頁面
├─ coming-soon.html ...... 施工中
│
├─ css/
│   └─ style.css ......... 全站外觀，改顏色間距都在這
│
├─ js/                     （程式，一般不用動）
│   ├─ main.js ........... 選單、圖片放大燈箱
│   ├─ i18n.js ........... 中英文切換

│   ├─ cv.js ............. 學經歷
│   └─ news.js ........... 動態
│
├─ data/                   ← 內容在這，改這裡網站就會變
│   ├─ manifest.json ..... 作品清單（首頁大圖也吃這份）
│   ├─ cv.json ........... 學經歷
│   └─ news.json ......... 動態
│
├─ i18n/                   ← 網站上所有文字
│   ├─ zh.json ........... 中文
│   └─ en.json ........... 英文
│
├─ images/                 ← 圖片放這
│   ├─ 香港玩具展.jpg
│   ├─ 2026/

│   ├─ 2024/
│   └─ 2015/
│
├─ public/ ............... 舊的測試圖，網站目前沒用到
│
├─ 啟動開發.bat .......... 雙擊開本機預覽
├─ robots.txt ............ 給搜尋引擎看的
├─ sitemap.xml ........... 給搜尋引擎看的
└─ 首圖尺寸建議.txt ...... 這份檔案


----------------------------------------
你最常會改的三個地方
----------------------------------------

  想加作品、換首頁大圖   →  data/manifest.json
  想改網站上的文字       →  i18n/zh.json（中）、i18n/en.json（英）
  想改外觀顏色、間距     →  css/style.css

  圖片不要直接丟進去就好，要在 manifest.json 裡加一筆，
  網站才知道要顯示它。
